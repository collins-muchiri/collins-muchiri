## How I work

1. Define the problem precisely before building.
2. Design around field realities, governance, and reporting requirements.
3. Deliver in stages with measurable milestones and clear checkpoints.
4. Document and hand over systems that teams can trust in production.

This approach keeps technical work grounded in operational realities rather than abstract demos.
