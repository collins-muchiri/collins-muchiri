# Zindi starter plan

A competition entry cannot be submitted by anyone other than the account holder, and must not be.
This file makes the first entry a two-hour task rather than a two-day one.

1. Account: create or sign in at zindi.club as the account holder. Choose a handle consistent with
   the portfolio name.
2. First competition selection criteria, in order: an open competition with a tabular or
   geospatial development-sector dataset; a deadline at least three weeks out; a leaderboard metric
   you can compute locally on the public split.
3. Starter pipeline: reuse weeks/week04 feature construction and weeks/week05 power reasoning.
   Baseline model first, a histogram of the target second, cross-validation grouped by the entity
   the test set hides, never by row.
4. Notebook hygiene: pinned versions, seed set, leakage check written as a comment at the top, and
   a limitations cell at the bottom. Public notebooks are portfolio artifacts whether you intend it
   or not.
5. Write-up: one paragraph for the profile README stating the metric, the rank, the field size and
   what you tried that failed. A mid-table entry with an honest write-up outperforms a hidden win.
