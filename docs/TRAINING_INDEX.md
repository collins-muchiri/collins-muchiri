# Training index

Curriculum built on this portfolio, in delivery order. Each module names its repository, its
prerequisite and its assessment. Facilitator materials for module 1 live in the companion learning
programme; the rest follow the same pattern.

| Module | Repository | Prerequisite | Assessment |
|---|---|---|---|
| 1. Sampling and bias on public SDG data | mck-sdg-east-africa-analysis, weeks/week01 | none | three check questions and a coverage disclosure footnote |
| 2. Intervals over differences | weeks/week02 | module 1 | interpret an interval to a programme director in five sentences |
| 3. Confounding by country | weeks/week03 | module 2 | draw the DAG and name what conditioning removes |
| 4. Regression and its diagnostics | weeks/week04 | module 3 | read the residual plot and state which standard errors are invalid |
| 5. Power and minimum detectable effect | weeks/week05 | module 4 | tell a client their design cannot see their effect, in writing |
| 6. Difference-in-differences and its failures | weeks/week06 | module 5 | plot a pre-trend and refuse a causal reading where it fails |
| 7. Reproducible research engineering | intelligent-profiling-engine | module 1 | clone to passing tests in one command |
| 8. Profiling governance and the human gate | intelligent-profiling-engine | module 7 | pass a profile action through the gate and through a refused attempt |
| 9. Ledger honesty: what integrity guarantees mean | humanitarian-coldchain-ledger | none | state what an operator with write access can alter |
| 10. From blueprint to vertical slice | Global-Climate-Food-Security-Intelligence-Platform-GCF-SIP- | module 1 | run the slice acceptance test |
| 11. Compliant lead generation and outreach gates | ngo-insights-ai | none | add a source and defend its terms in one paragraph |
| 12. Dashboard to decision | mck-dashboard-to-insight | modules 1 and 5 | write the decision sentence a director would sign |

Rule for trainers: modules 5, 8 and 9 are the ones where participants most often resist the honest
answer. Budget discussion time there, not in the coding sections.
